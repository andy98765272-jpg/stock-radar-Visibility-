# STOCK RADAR 台股短線自動選股

每個交易日收盤後自動抓證交所(上市)行情、三大法人與處置股,依三大策略篩選、評分,
產出每檔的進場價、停損、停利、建議股數與六個必答說明,並把歷史訊號用後續日線模擬成交,統計績效。
全部只用 Python 標準函式庫,沒有第三方套件。

## 第一次使用(約 10 分鐘)

1. 在 GitHub 建立一個新 repo,把這個資料夾全部推上去。
2. Settings → Pages → Source 選 `Deploy from a branch`,Branch 選 `main`、資料夾選 `/docs`。
3. Actions 分頁 → `daily` → `Run workflow` 手動跑一次。第一次要補約 100 個交易日的歷史,
   證交所限速,每次請求間隔 3.5 秒,大約需要 8 到 10 分鐘。
4. 完成後網站在 `https://<帳號>.github.io/<repo>/`。之後每週一到週五台北時間 17:30 自動更新。

### 先在本機確認資料來源

```
python -m radar doctor
```

它會抓最近一個交易日的行情、法人與處置股,印出解析結果。**請在正式排程前先跑一次。**
本專案在開發時,測試環境連不到證交所,所以解析邏輯是用「依欄位名稱比對」的方式寫成並以模擬回應測試,
還沒有用真實回應驗證過。如果 `doctor` 顯示格式不符,把輸出貼給維護者即可修正。

如果 GitHub Actions 的雲端 IP 被證交所擋掉(doctor 步驟失敗),改在自己的電腦用系統排程跑
`python -m radar daily`,再把 `docs/data` 推上去。

## 指令

| 指令 | 用途 |
| --- | --- |
| `python -m radar doctor` | 檢查資料來源 |
| `python -m radar daily` | 更新資料 + 選股 + 績效統計(排程用) |
| `python -m radar update --days 200` | 只補資料 |
| `python -m radar screen --date 2026-11-20` | 對指定日期選股 |
| `python -m radar backtest --days 60` | 重播過去 60 個交易日 |
| `python -m radar watch` | 盤中監控候選名單(本機執行) |

## 盤中監控

盤中不掃全市場,只盯盤後選出的候選名單(最多 20 檔)。

```
python -m radar daily          # 先產生候選名單
python -m radar watch          # 開盤時間執行,預設每 5 秒向證交所抓一次報價,13:35 自動結束
python -m radar watch --interval 3   # 想更快可以調,不建議低於 3 秒(會被限流)
python -m http.server -d docs  # 另開視窗,瀏覽 http://localhost:8000 的「盤中監控」分頁
```

網頁每 1 秒檢查一次是否有新資料,資料實際更新速度取決於上面的抓取間隔。

每檔會顯示現價、漲跌、盤中量比、與進場價及停損的關係,並判斷:

- 等待觸及進場價
- 已觸價,符合進場條件
- 已觸價,但量比不足(帶量突破型必須量比達標)
- 跳空過大,不追
- 跌破停損,訊號失效

盤中量比 = 目前累計成交量 ÷(前 5 日平均成交量 × 此時段預期累計比例)。預期比例是依一般 U 型量能曲線估計
(09:30 約 22%、10:30 約 45%、12:00 約 70%),不是精確值。

限制:報價有數秒延遲;證交所即時報價介面沒有公開的穩定規格,首次使用請在開盤時間跑
`python -m radar watch --once` 實測;只支援上市個股(上櫃、興櫃不在範圍內)。

## 選股邏輯摘要

- 基本條件:股價 15~300 元、20 日均成交金額 ≥ 5,000 萬、MA5 > MA10 > MA20 且股價在 MA20 之上、
  跳空 ≤ 3%、乖離不過大、排除處置股與資料不完整者、僅限一般個股(排除 ETF、權證等)。
- 策略:帶量突破、拉回支撐、強勢續攻,條件見網站「參數與說明」。
- 停損 = 支撐 − 0.3 × ATR;停利 = 進場價 + 2.5 / 4 × ATR;報酬風險比低於 1:2 不入選。
- 評分 100 分(技術 30、價量 25、籌碼 20、動能 15、風險 10),低於 75 分不入選。
- 建議股數把手續費、證交稅、滑價算進每股風險。

所有參數都在 `config.json`。

## 已知限制

- 「動能與題材」無法自動判斷題材,以價格動能計分;籌碼面只用三大法人買賣超。
- 量比在盤後是用整天成交量計算。
- 績效回測用日線,看不到盤中先後順序,模擬假設見網站「績效追蹤」。第一次回測的參數是初始值,
  請依回測結果與實盤訊號持續調整,不要只看勝率。
- 只涵蓋上市股票。
- 這是輔助工具,不是投資建議,也不保證獲利。
